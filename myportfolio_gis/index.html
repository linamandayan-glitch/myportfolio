GIS Portfolio
Detta projekt visar ett komplett open source GIS-arbetsflöde med öppna data från Trollhättans stad. Datan hanteras och stylas i QGIS, konverteras till och lagras i PostGIS med hjälp av ogr2ogr (GDAL), publiceras som WMS/WFS-lager via GeoServer och visualiseras som en interaktiv webbkarta med OpenLayers. Klicka på respektive bild nedan för att utforska detaljerna i varje del av arbetsflödet.

Data

Öppna GeoJSON-data från Trollhättans stad. Klicka för att se detaljer om dataset och struktur.

GeoServer

Publicering av WMS/WFS-lager och styling med SLD. Klicka för att se GeoServer-konfigurationer.

QGIS

Visualisering och styling av geodata med QGIS. Klicka för detaljer och skärmdumpar.

OpenLayers

Interaktiv webbkarta byggd med OpenLayers. Klicka för att sedetaljer.
