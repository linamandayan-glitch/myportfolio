Data Analyst Portfolio (Under bearbetning ... )
Detta projekt demonstrerar hur Power BI används för visualisering med öppna data från Trollhättans stad. Data hanteras och integreras i databasen och laddas sedan, via ett ETL-flöde, in i Power BI, där relationer mellan tabeller definieras. Data visualiseras och en interaktiv rapport skapas. Klicka på respektive bild nedan för att utforska detaljerna i varje del av arbetsflödet.
